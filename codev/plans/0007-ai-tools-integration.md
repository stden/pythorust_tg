## 📋 Задачи по приоритетам

### P0: Критичные — Инфраструктура агентов

#### TASK-101: Настроить мультитерминальную работу
- **Статус:** 🔲 TODO
- **Оценка:** 4h
- **Описание:** Организовать параллельную работу 4-6 терминалов Claude Code без конфликтов файлов
- **Решение из чата:**
  - Каждый агент в своей git-ветке
  - Модульная система обязательна
  - Не допускать работу над одними файлами
- **Критерий:** 4 терминала работают параллельно над разными модулями

#### TASK-102: Разделить роли агентов (Coder/Tester/Refactorer)
- **Статус:** 🔲 TODO
- **Оценка:** 6h
- **Описание:** Настроить system prompts для разных ролей
- **Промпты из чата:**
  - Coder: "Use TDD. Ensure 100% tests coverage. DRY, KISS + SOLID"
  - Tester: Фокус на edge cases и coverage
  - Refactorer: Оптимизация и чистка кода
- **Критерий:** 3 агента с разными ролями работают последовательно над задачей

#### TASK-103: Интегрировать Gemini как архитектор/ревьюер
- **Статус:** 🔲 TODO
- **Оценка:** 4h
- **Описание:** Gemini 3.0 для архитектурных решений и code review
- **Преимущества:** Высокие лимиты, не кончаются, хорош для анализа
- **Файлы:** `integrations/gemini_reviewer.py`
- **Критерий:** Автоматический review PR через Gemini API

## 🔧 Технические заметки из чата

### Промпты для агентов
```
System prompt для Coder:
"Use TDD. Ensure 100% tests code coverage. DRY, KISS + SOLID"

Разделение ролей:
- coder: пишет код
- tester: пишет тесты
- refactorer: оптимизирует
```

### Архитектура мультиагентов
```
Gemini 3.0 → Архитектор и ревьюер
Opus 4.5 → Кодер и тестер
ChatGPT → Секретарь и ТЗ

Feature-branches для каждого агента
LightRAG + Qdrant для знаний проекта
```

### Оплата из РФ
- RedotPay через Google Play/App Store
- Morune банковская карта
- Виртуальные карты ~200₽
- store.rg-adguard.net для offline MS Store

### Лимиты моделей
| Модель | Лимит | Стоимость |
|--------|-------|-----------|
| Claude Pro | Средний | $20/мес |
| Claude Max | 330М токенов = 11% недели | $100/мес |
| Claude Ultra | Безлимит Opus | $200/мес |
| Cursor Ultra | 2 дня интенсива | ~$20/мес |
| Gemini Pro | Высокий, не кончается | $20/мес |
